# Kulitha Hansaja — Personal Digital Marketing Portfolio

A luxury minimalist static portfolio website built with semantic **HTML5, modern CSS3, and vanilla JavaScript**.

---

## 🎨 Design System: Luxury White, Satin Gold & Brushed Silver with Subtle Radiance

- **Background & Surfaces**: Layered luxury off-white (`#FBFBFA`), crisp white cards (`#FFFFFF`), and refined brushed silver tones (`#F0F2F5` / `#F8FAFC`).
- **Subtle Radiance Glow**: Tasteful ambient gold and silver lighting (`rgba(197, 160, 89, 0.12)`) on cards, hero image, and active controls.
- **Satin Gold Accent**: `#C5A059` / `#D4AF37` / `#B38B3F` (Primary CTAs, active indicators, card highlights, awards).
- **Brushed Silver & Platinum Accent**: `#E2E8F0` / `#CBD5E1` / `#64748B` (Hairline borders, secondary buttons, tech tag containers).
- **LinkedIn Profile**: [linkedin.com/in/kulitha-hansaja-1a69a0203](https://www.linkedin.com/in/kulitha-hansaja-1a69a0203)
- **Typography**: Google Fonts `Space Grotesk` (Headings, 600-700) + `Inter` (Body, 400).
- **8px Spacing Grid**: Strict multiples of 8px for balanced editorial layout.
